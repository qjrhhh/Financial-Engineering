# Financial-Engineering

券商金工研报的复现代码合集。目录结构参照 [QuantsPlaybook](https://github.com/hugo2046/QuantsPlaybook)：**按研究主题分文件夹**，每个主题下研报 PDF 放在外层，可运行代码统一放在 `py/` 子目录，方便「看报告 → 跑代码 → 对结论」。

## 目录结构

```
Financial-Engineering/
├── B-因子构建类/              选股 / 量价 / 资金流类因子挖掘
│   ├── 分钟资金流因子/         开源证券·市场微观结构系列（31）
│   ├── 隔夜相关性因子/         隔夜-日间相关性构造选股因子
│   ├── 偏度因子策略/           偏而不倚：偏度因子策略再研究
│   └── 商品期货多因子筛选/     商品期货上的多因子应用
├── C-择时类/                  择时信号、席位数据、CTA、深度学习
│   ├── 国债期货席位择时/
│   ├── 股指期货席位策略/
│   ├── 成交持仓价格三维视角/   流量立方体 Flow Cube
│   ├── 扩散图神经网络CTA/
│   └── 绝对收益视角下的技术指标/  东吴·深度学习系列之二
├── D-组合优化/                指数增强、对冲、组合构建
│   └── 风格轮动下的A500对冲策略/
└── E-期货与衍生品/            套利、期权、期货多头替代
    ├── 国债期货统计套利/       上篇 + 下篇
    ├── 国债期货多头增强/
    ├── 期权吃贴水策略/
    └── 跨品种套利-原木与螺纹钢/  下篇
```

每个主题目录形如：

```
主题名/
├── XXXX.pdf          # 研报原文
└── py/               # 复现代码（.ipynb / .py）
```

## 运行说明

- 多数 notebook 依赖 **聚宽 JoinQuant 研究环境**（`jqdata` / `jqdatasdk`）取数，本地运行需自行替换数据接口。
- `B-因子构建类/分钟资金流因子/py/分钟资金流因子的构建方法.py` 可直接整段贴进聚宽研究环境运行，文件头已注明与研报的差异（聚宽无逐笔大小单数据，用分钟 K 线做代理）。
- 建议环境：Python 3.8+，pandas / numpy / matplotlib / scikit-learn；个别主题若需额外依赖，见对应目录（后续可按主题拆分 `requirements.txt`）。
